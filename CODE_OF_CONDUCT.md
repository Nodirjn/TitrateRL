# Code of conduct

We want TitrateRL to be a respectful and productive place to work.

* Be kind and assume good intent. Critique code and ideas, not people.
* Give and accept review feedback constructively; explain the reason behind a request.
* Credit the work of others, including the authors of the models and tools we build on.
* Be honest about results, including negative ones and limitations.
* Report unacceptable behavior to the course supervisor, Dr. Eugene Castro.
